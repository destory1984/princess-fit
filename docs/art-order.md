# 그림 주문 (ChatGPT)

처자·옷·가구 그림을 ChatGPT의 이미지 생성으로 받는다. Space Oddity
(`destory1984/oddity_claude`, 기획서 11.13)에서 열두 장을 받아 쓴 방법을 그대로
가져왔다. 2026-10-03.

```bash
scripts/art-order.sh <작업 폴더> <주문 글.txt> <받을 파일.png> [참고 그림 ...]
# 예: 리나의 체육복을 base.png와 같은 자세로
scripts/art-order.sh art-orders/rina rina-gym.txt rina-gym.png assets/outfit/base.png
```

- Codex CLI(`codex exec`)를 사람 없이 돌린다. 전하의 ChatGPT 구독으로 그린다.
  `codex login status`가 로그인돼 있어야 하고, 키는 스크립트에 없다.
- 스크립트가 주문 글 앞에 「이미지 생성 기능으로 그려라, 코드로 그리지 마라」를 붙인다.
- 작업 폴더는 `art-orders/` 아래에 둔다(저장소에 올리지 않는다). 주문 글, Codex의
  기록, 받은 그림이 거기 남는다.
- Windows에서는 Git Bash로 돌린다(PowerShell 5.1은 한글을 깨뜨린다, NOTES.md 6절).
- 한 장에 2분쯤.

## Refit에서 주문 글에 꼭 넣을 것

1. **배경은 완전히 투명하게, 바닥 그림자 없이.** Claude Design이 신발 밑에 그림자
   판을 깔아 알파 측정을 망친 적이 있다(NOTES.md 3절). 받은 뒤 네 귀퉁이가 정말
   투명한지 본다.
2. **같은 자세는 참고 그림으로 맞춘다.** 옷은 `assets/outfit/base.png`(또는 그 아이의
   `base_*.png`)를 참고로 넣고 「이 사람의 자세·비율·크기에 그대로 겹치는 옷만」이라
   쓴다. 처자의 새 그림은 그 아이의 `assets/advisors/*.png`를 넣는다. 먼저 받은
   그림을 다음 주문의 참고로 넣으면 한 벌로 맞춰진다.
3. **글자를 그리게 하지 않는다.** 받은 그림의 글자는 믿지 않는다(Oddity에서
   「제한」이 「제압」으로 나왔다). 글자는 앱이 쓴다.
4. 아이마다 다른 것을 주문 글 첫머리에 적어 둔다 — 리나·피아·유키가 한 화가의 손에서
   나와도 서로 다른 사람으로 보이게. 생김새·머리·눈매·자세의 버릇을 한 문단으로.

## 받은 뒤

1. 앱이 쓰는 크기로 줄인다.
2. 옷·가구는 `node scripts/garment-fit.mjs <파일> <부위>`로 자리를 잰다. 눈대중하지 않는다.
3. 앱에서 눈으로 본다 — 특히 얼굴. 얼굴이 이 일을 외주로 돌린 까닭이다.

## 첫 주문에서 배운 것 (2026-10-03)

몸틀 후보 넷(2.5 · 3 · 3.5 · 4등신)과 세 아이 시안을 받았다. 그림은 `art-orders/2026-10-03/`에
있고 `index.html`을 열면 나란히 보인다.

- **참고 그림 없이도 주문할 수 있다.** 스크립트가 늘 「참고 그림을 보라」고 적어서 첫 일곱
  장이 빈손으로 돌아왔다. 고쳤다.
- **배경은 투명하게 온다.** 검게 보이는 것은 보는 도구가 투명을 검게 칠한 것이다. 다만 몸
  둘레에 반투명한 테가 끼어 어두운 화면에서 빛처럼 보인다.
- **받은 그림은 도트처럼 보일 뿐 도트가 아니다.** 1024 × 1536쯤이고, 「한 점」이 18 → 24픽셀의
  덩어리이며 덩어리 크기가 고르지 않다.
- **`scripts/sprite-clean.py`가 이 셋을 고친다.** 투명을 딱 자르고, 몸을 테두리에 맞춰 잘라
  높이 64점으로 줄이고(덩어리마다 가장 많은 색을 고른다. 평균을 내면 검은 테두리가 갈색이
  된다), 색을 16개로 줄인다.
  ```bash
  python -X utf8 scripts/sprite-clean.py art-orders/2026-10-03/base-a/base-a.png
  ```
- **64점에서는 등신이 높을수록 얼굴이 사라진다.** 4등신 몸틀의 머리는 가로 10점쯤이라 눈과
  입을 둘 자리가 없고, 유키의 안경은 얼룩이 됐다. 2.5등신은 머리가 가로 20점이라 눈매가
  남는다. 몸틀을 고를 때 이것이 가장 큰 갈림이다: 얼굴(2.5 → 3등신)이냐, 운동 동작의
  무릎과 허리 각도(3.5 → 4등신)냐. 높이를 64보다 키우는 길도 있다.
- **「담백하게」를 적지 않으면 몸매를 강조해서 그린다.** 다시 주문할 때 「몸매를 강조하지
  않는다, 운동하는 사람의 담백한 몸」을 넣으니 줄었다. 주문 글에 늘 넣는다.
- **세 아이 시안은 등신이 제각각으로 왔다**(리나 3, 유키 6, 피아 3.5). 몸틀을 정한 뒤 그
  몸틀을 참고 그림으로 넣어 다시 받아야 한 벌이 된다.
