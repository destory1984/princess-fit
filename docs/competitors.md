# Refit과 다른 운동 앱 — 견주어 본 것

2026-09-22에 적음. 다른 앱에 대한 것은 기억에 기댄 것이라 요금·기능은 바뀌었을
수 있다. 무엇을 정할 때 이 문서를 근거로 쓰기 전에 한 번 확인한다.

이 문서는 **다음에 무엇을 지을지** 고르려고 둔다. 한 일은 NOTES.md에 적는다.

---

## 1. 견준 앱

| 앱 | 한 줄 |
|---|---|
| **Strong** | 빠르고 깔끔한 기록의 기준. 무료는 루틴 수 제한 |
| **Hevy** | 무료가 넉넉하고 소셜(피드)이 강함 |
| **Fitbod** | 회복 상태로 AI가 그날 운동을 짜 줌. 구독 |
| **JEFIT** | 종목 DB 최대, 커뮤니티. 광고 많고 무거움 |
| **플랜핏** (국내) | AI 루틴, 한국어, 초보자 |

## 2. Refit이 나은 것

1. **게임과 기록이 한 몸.** 번 골드로 아이를 먹이고 입히고 가르친다. 위 앱
   어디에도 없다. 운동 앱이 무너지는 곳은 3~4주 차 이탈이고, 정든 아이는
   배지보다 강한 까닭이 된다.
2. **기록을 잃지 않음.** 경쟁 앱 별점 1의 태반이 「기록이 날아갔다」.
   못 보낸 쓰기 줄 세우기, 치는 동안 저장, CSV·JSON 내보내기·가져오기.
3. **셈이 정직함.** 워밍업 제외, 빈 운동 무보상, AI가 지어낸 숫자 버림.
4. **세부 기능.** RPE 반영 이중 점진 과부하, 좌우 불균형, 랙 무게 맞춤,
   워밍업 램프, 대체 종목. Strong + Fitbod의 강점을 합친 수준.
5. **한국어 설계.** 초성 검색, 별칭, 조사 고르기.
6. **개인 정보.** AI 조언은 각자 PC의 Ollama, 폰마다 끌 수 있음.

## 3. Refit이 못한 것

1. **폰 생태계 연동 없음** — Apple 건강, 수면, 워치, 위젯. 개발 빌드 대기.
   가장 큰 공백.
2. **처음 온 사람 이끌기가 약함** — 「오늘 뭐 하지?」에 바로 답하는 쪽은
   Fitbod·플랜핏.
3. **사회적 기능 없음** → 2026-09-22에 첫 판을 지음(5장).
4. **로그인·신뢰** — 이메일만. 비밀번호 찾기 메일 틀 미설정.
5. **종목 수·동작 영상** — JEFIT은 천 개가 넘고 그림이 있다.
6. **그림 값** — 게임이라는 장점은 옷·가구·아이 그림을 계속 요구한다.
7. **저절로 닫힌 운동의 골드** → 2026-09-22에 고침(`workouts.paid_at`).

**겨루기**(순위표·챌린지), **함께 버티기**(짝·무리 인증).

## 5. Refit이 고른 것

Refit의 동기는 숫자가 아니라 아이다. 그래서 겨루기가 아니라 **아이를
보여 주고 서로의 아이를 찾아가는 쪽**으로 갔다.

| 기능 | 상태 | 어디 |
|---|---|---|
| 친구 코드로 맺기 | 지음 | `app/friends.tsx`, `supabase/social.sql` |
| 친구 방 구경 | 지음 | `app/friend/[id].tsx` — 품계·능력치 판은 뺀다 |
| 골드 선물 10·30·50G, 친구마다 하루 한 번 | 지음 | `send_gift` |
| 같은 날 운동하면 둘 다 +20G | 지음 | `claim_together`, 운동 완료 때 |
| 공유 카드에 아이 | 지음 | `components/BragCard.tsx` |

**순위표는 일부러 안 한다.** 워밍업을 빼고 빈 운동에 주지 않을 만큼 셈을
지켜 왔는데, 순위는 숫자를 부풀릴 까닭을 준다.

### 다음에 해 볼 만한 것

- 친구 방에 **한마디 남기기**(방명록). 짧은 글 하나, 욕설 거르기 필요.
- 친구가 운동을 마치면 **알림**. 푸시 서버가 없으니 앱을 열 때 모아 보이기부터.
- ~~함께 버틴 날 수~~ → 2026-09-23 지음. 친구 목록에 「🔥 함께 N주째」(2주부터). 한 주에 같은 날 한 번이면 이어진다 — 매일 하는 사람은 없고, 쉬는 날마다 끊기면 제대로 하는 사람을 벌한다.
- 선물로 골드 대신 **옷·가구 보내기**. 가진 것이면 막아야 한다.
- 부계정으로 골드 몰아주기 막기 — 지금은 금액·횟수 상한뿐.
